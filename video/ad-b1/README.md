# 광고 b1 — 모션 그래픽 v2 (1920×1080 · 60fps · 30초)

v1(망점 캐릭터 · 해결 카드 3장을 한 화면에 묶음)은 「뭐가 좋은지 모르겠다 · 캐릭터가 싸 보인다」 피드백으로 버리고 다시 만들었다.

**v2 원칙**
- 사이트(fixable.) 톤 그대로 : 흰 바탕 · 검정 글자 · 회색 선, 강조는 크기 · 굵기 · 여백. 라벨은 `(01) LABEL`(Jost), 제목 Pretendard 600, 어두운 둥근 기능 카드, 검정 알약 버튼. 빨강은 문제 표시(✕)와 쿠폰에만 조금
- 캐릭터 없음. 쇼핑몰 화면(휴대폰)이 내용을 전한다
- 고민 3개를 **하나씩** : 흰 화면에서 「고민」(Before 휴대폰) → 어두운 카드가 펼쳐지며 「fixable 의 답」(After 휴대폰을 Before 옆에 나란히). 같은 쇼핑몰(MY SHOP)이 스킨만 바뀐 비교라 차이가 바로 보인다
- 장면 넘김은 사이트 기능 카드처럼 아래에서 올라와 덮기

| 파일 | 내용 |
|---|---|
| `b1.html` | 장면 · 움직임 전부. 브라우저로 열고 `?t=13.5` → 그 초 화면, `?v=B` → B 훅 |
| `render.js` | `node video/ad-b1/render.js` (A) · `… B` · `… A --stills 1.5,9.9` (정지 화면) |
| `out/b1_A.mp4` · `out/b1_B.mp4` | 결과 영상 (나레이션 · 소리 없음) |
| `fonts/` | Pretendard(subset) · Jost · Instrument Serif |

필요 : Node + `playwright`(chromium) + ffmpeg. 전역 playwright 는 `NODE_PATH=$(npm root -g)`.
