# 광고 b1 — 모션 그래픽 (1920×1080 · 60fps · 21초)

레퍼런스(망점 캐릭터 · 파란 강조 · `// 라벨` 모노 글자 · 한 줄씩 올라오는 문구 · 카드 격자 + 도장)를 따라
`b1.html` 한 장에 타임라인을 짜고, `render.js` 가 프레임마다 찍어 mp4 로 굽는다.

| 파일 | 내용 |
|---|---|
| `b1.html` | 장면 · 움직임 전부. 브라우저로 열고 `?t=13.5` → 그 초 화면, `?v=B` → B 훅 |
| `render.js` | `node video/ad-b1/render.js` (A) · `node video/ad-b1/render.js B` · `… A --stills 1.5,9.9` (정지 화면) |
| `out/b1_A.mp4` · `out/b1_B.mp4` | 결과 영상 (나레이션 · 소리 없음) |
| `fonts/` | Pretendard(subset) · JetBrains Mono · Instrument Serif |

필요 : Node + `playwright`(chromium) + ffmpeg. 전역 설치된 playwright 를 쓸 땐 `NODE_PATH=$(npm root -g)`.
